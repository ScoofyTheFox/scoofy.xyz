scoofy.xyz - custom guestbook avatars
=====================================

Drop your own profile images / gifs in THIS folder, then list them in
../../config.js under `pfps`.

Example:
  1. put a file here:      assets/pfps/tuffwolf.gif
  2. add it in config.js:  pfps: [ ... , 'assets/pfps/tuffwolf.gif' ]

Notes:
- gifs animate. png / jpg / webp / svg all work too.
- any size is fine - it's shown as a square tile.
- ONLY ADD TO THE END of the pfps list in config.js. Never reorder or delete
  existing entries, or old signatures point at the wrong face (they store the
  position number). Everything's temporary anyway, but be nice to past-you.
