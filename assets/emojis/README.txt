scoofy.xyz - custom emoji placeholders
======================================

These are the :name: inline emojis. Right now they're PLACEHOLDERS: the site
shows a built-in fallback (the flags render as little SVGs; :scoofy: / :fox:
show your fox art). Drop a real image here with the matching name to override.

Expected files (png; or change the path in ../../config.js or script.js):
  mlm_flag_emoji.png       ->  :mlm:
  usa_flag_emoji.png       ->  :us:  /  :usa:
  romania_flag_emoji.png   ->  :ro:  /  :romania:
  scoofy_emoji.png         ->  :scoofy:
  fox_emoji.png            ->  :fox:

Keep them small and roughly square (they render ~1em tall inline).
To add a NEW emoji: put the file here and add a line to config.js emojis.
